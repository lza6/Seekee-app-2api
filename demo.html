协议要点（已还原并实测）：
· 签名: signVal = md5(b64(AES-ECB(urlencode(参数值拼接 + curTime))))

· 响应: code 00000 时 data 为 AES-ECB 加密，用请求侧 aesKey 解密
· 生图链路: textToImage → taskId → getTaskResult 轮询 → OSS 图片 URL（实测 ~8-20s 出图）
